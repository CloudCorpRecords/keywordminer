# Changelog

## 0.1.0 (2026-10-27)

- Initial release: five Marketing Miner Profilers API tools —
  single and batch keyword search volume, keyword suggestions,
  website stats, and website stats range with optional
  competitor comparison — plus a `search-volume` CLI command.
- Token from `MARKETING_MINER_API_TOKEN` (alternates
  documented in the README); a missing token is an honest
  error, never fabricated data. `response_format` renders
  markdown (default) or the raw API JSON.
